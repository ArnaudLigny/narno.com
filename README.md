# Narno.com

Source code and content of [narno.com](https://narno.com).

The website is automatically built by [Cecil](https://cecil.app) + [GitHub Actions](https://github.com/features/actions) when content is updated, and deployed to [GitHub Pages](https://pages.github.com).

[![Build and deploy to GitHub Pages](https://github.com/ArnaudLigny/narno.com/actions/workflows/website.yml/badge.svg)](https://github.com/ArnaudLigny/narno.com/actions/workflows/website.yml)

## Build & serve locally

```bash
curl -LO https://cecil.app/cecil.phar
php cecil.phar serve
```
